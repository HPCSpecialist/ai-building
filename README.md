# ساختمان هوش مصنوعی

نقشه‌ی ساختارمند یادگیری و نمونه‌کار — از پی ریاضی تا رصدخانه‌ی پژوهش.

## استعاره‌ی برج

- هرچه پایین‌تر، بنیادی‌تر و فیزیکی‌تر.
- هرچه بالاتر، انتزاعی‌تر و نزدیک‌تر به کاربرد انسانی.
- **آسانسور:** سوال → معنا → نقشه → ابزار → کد.
- **دو راه‌پله:** نظریه، پیاده‌سازی.

## مقیاس سطح

| سطح | معنا | تست |
|---|---|---|
| ۰ | نمی‌دانم | — |
| ۱ | نامش را شنیده‌ام | می‌توانم بگویم به چه دردی می‌خورد، نه چطور |
| ۲ | می‌توانم توضیح دهم | می‌توانم به یک غیرمتخصص توضیح دهم |
| ۳ | می‌توانم پیاده کنم | از صفر، بدون کپی، روی سخت‌افزار خودم |
| ۴ | می‌توانم تدریس/عیب‌یابی کنم | می‌توانم خطا را پیدا کنم و به دیگری یاد بدهم |

⬜ = هنوز ارزیابی نشده.
